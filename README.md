# 专业与圈层幽默 · 公众评分

评分页面：https://isab-org.github.io/Meme_and_Jokes_Rating/

这是独立的公开评分仓库。当前暂保留原始五类（铁路、航空、知乎回答、苏联、其他领域），共158条：首轮材料与首轮之外人工评分≥7的条目。编号沿用领域前缀＋四位数字＋GEM（如R0001GEM、XA0001GEM）。不包含研究主仓库的模型回答、模型分数、个人评分文件或本地备份。

## 参与评分

1. 打开上方页面，输入组织者提供的 access 密码后开始评分，无需GitHub登录。
2. 筛选熟悉的领域，阅读原文、中文译文及图片，可以只评部分条目。
3. 填写「主机制是否有误」「解析是否完善」和1–10分的好笑程度，可选填写修正建议。前两项默认否/是，未操作的默认值不表示已审核。
4. 点击「导出评分 JSON」，把文件通过邀请渠道发回组织者。页面不会自动提交评分。

左右键切换，数字1–9打分，0代表10分。编辑输入框或下拉选项时不会触发快捷键。

评分仅保存在当前浏览器的localStorage。导出文件包含随机匿名编号、条目编号、分数、修正备注、更新时间及数据集内容哈希。没有要求提供姓名、邮箱或领域熟悉度。换设备或清理网站数据前请导出JSON，在另一设备用「导入评分」继续。同一人的多个文件可按更新时间合并；页面阻止将其他匿名参与者的评分混入已有记录。

## 数据说明

- 260条结构化候选来自随附的既有领域200条和新领域60条提案，保留已有译文和解析。本次不将提案自述的AI审核通过或高分视为人工结论。
- 另200条短笑话的原文件metadata明确标注generated，页面将它们单独列为「AI生成短笑话」，不当作已经查证的公开网络材料。这批补充中文译文，未编造来源或独立笑点解析。
- 原文及英语双关均保留；无法等效翻译的地方标注「无法翻译」并附意译。译文和AI解析待人工复核。
- 图片和原梗的权利属于原权利人；本仓库不对第三方材料授予额外许可。公开源链接可在具体条目中查看，缺失处明确留空。

## JSON和汇总

`docs/data.json` 是公开条目，`docs/review-state.js` 定义导入、导出与合并逻辑。当前 dataset 为 `gem_first_round_plus_human7_v1`，schema_version为2.1，dataset_sha256绑定当前158条的公开内容版本。

组织者将回收文件存入本地`received_reviews/`，运行：

```bash
python3 tools/aggregate_reviews.py received_reviews --output ratings_merged.csv
```

同一匿名编号的多次导出按每个条目的更新时间去重，保留最新评分。输出一份逐条汇总CSV和一份逐人逐条明细CSV；分母只包含实际填写的好笑分，空白不会变成0分。脚本拒绝数据集哈希不符的文件。收到的JSON和汇总CSV都已被.gitignore排除，请不要将参与者的备注上传公开仓库。

## 部署与维护

网站是无后端的HTML/CSS/JavaScript，GitHub Pages从main分支的`/docs`目录发布。页面使用按日期轮换、最近7天有效的前端 access 密码门；由于密码校验逻辑随静态页面下发，这只是邀请筛选，不是安全认证。若需要真正保密，应迁移到带后端鉴权的服务。静态页面本身不接受评分上传。

本地预览：`python3 -m http.server 8880 --directory docs`。

开发校验：`node --test tests/review-state.test.js`。修改公开条目时须同步更新dataset_version和dataset_sha256，避免混用不同版本的评分。`docs/images/`保存页面需要的全部原图。

托管访问仍受GitHub Pages自身服务规则和日志政策约束；本应用不接入第三方分析、埋点或远程评分接口。
